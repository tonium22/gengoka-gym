# 言語化ジム

言語化の練習アプリ（PWA）。元ネタは PIVOT「瞬間言語化トレーニング」前編・後編（`knowledge/gengoka-training.md`）。

## 中身

| 悩み | トレーニング | 時間 |
|---|---|---|
| ① 思いつかない（具体化） | 「なぜ？」×5回 / 「どういうこと？」×5回 / 5W1H | 1分 / 1分 / 3分 |
| ② まとまらない（抽象化） | 共通点10個 | 2分 |
| ③ 伝わらない（具体と抽象1:1） | 具体と抽象をセットで / たとえ話 | 5分 / 5分 |

- ホームの「今日のメニュー」は①②③から1つずつ（日替わり）
- お題はランダム。自分でお題を書くこともできる
- 記録はこの端末の中（localStorage）だけ。外には送らない
- 連続日数・7日間グラフ・ふりかえりメモ・コピー

## ファイル

- `data.js` お題とトレーニングの説明（お題を増やすならここ）
- `app.js` 画面と動き
- `style.css` 見た目（スマホのダークモード対応）
- `sw.js` オフライン用。ファイルを変えたら `CACHE` の番号を上げる

## 手元で開く

```
cd gengoka-app && python3 -m http.server 8771
```
→ http://localhost:8771
